# Sumsi – Children's Art Competition Website

A responsive website developed in 2024 as part of my **Web Development training program**.

The project was created for a children's art competition organized by **Raiffeisen Bank**, featuring Sumsi, the bank's well-known bee mascot.

## About the Project

The goal was to design and develop a user-friendly website for the competition, with a focus on responsive design, clear navigation, and an engaging visual experience.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS

## Features

- Responsive website layout
- Interactive elements using JavaScript
- Competition-related information and content
- Legal information pages (Privacy Policy, Cookies, Terms and Conditions)

## Project Information

**Year:** 2024  
**Type:** Web Development Training Project  
**Purpose:** Educational / Portfolio

This project was developed for educational purposes during my Web Development training program and is not an official Raiffeisen Bank website.
